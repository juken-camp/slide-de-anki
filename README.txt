表示
通常の学習：「1 / 56問」の右に「入試過去問」と年度一覧。
検索した問題：「答えを見る」の下に同じ表示。
令和はR、平成はH。例：R7④(1)、H31①(4)。新しい年度から並べます。
年度一覧は横スクロール。年度を押すと、その入試で問われた内容と対応の説明を表示。
問題を裏返しても同じスライドではスクロール位置を維持。

現在の掲載範囲
分析表で整理した654スライド・814対応を掲載。
同じ名称を答える対応と、関連知識の対応を詳細画面で区別。
候補・年度保留は表示しません。対応なしの画面に「未出題」とは表示しません。
令和8年度は未収録。全年度・全スライドの照合が完了した意味ではありません。
入試問題原本との照合は未完了です。この点は詳細画面にも表示します。

動作への配慮
対応データは学習画面を開いたときに別途取得し、問題画像の表示は待たせません。
取得に失敗した場合も、既存のスライド学習はそのまま動作します。
教材ID・問題ID・学習記録・チャット履歴・設定・APIは変更していません。
