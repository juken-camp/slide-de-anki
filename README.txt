歴史の暗記202グルチャ　実装ファイル（2026年11月8日）

■ 何が入っているか
・31カテゴリー／202重要事項／724吹き出しの会話台本
・第1〜3話も全面改稿（元の試作をそのまま流用していません）
・会話中に「何が起きた→なぜ起きた→次に何が変わった」の流れを入れています
・章の最初と最後に重要事項の一覧をまとめています
・一人の連続発言は間隔の小さい複数バブル、別の人の発言とは間を空けています
・吹き出しをタップで補足解説。もう一度タップで解除
・全31話の目次、検索、途中位置の保存、Cyber/Nekoponテーマ連動
・現時点で再生ボタン／あとから自動再生する機能はありません（後の工程）

■ すぐ内容を見る
別添「歴史の暗記202_動作プレビュー.html」をMacのブラウザで開きます。
公開用と同じ台本・配置ですが、プレビューは独立した単一HTMLなのでGitHubへのアップロードは不要です。
ブラウザの環境によっては画像の読み込み先（history-icons/）がなく、人物画像は絵文字表示になります。

■ GitHubに導入する
1. ZIPを解凍し、次を既存リポジトリの同じパスへ追加します。
     history202-chat.html
     history202/chapters.json
     history202/config.json
     history202/participants.json
     history202/room.css
     history202/room.js
     history202/launcher.js
2. GitHubの最新版himiko.htmlを編集し、最後の </body> の直前に次の１行を追加します。
     <script src="history202/launcher.js?v=20261108-1" defer></script>
   （もしくはMacで最新himiko.htmlを保存し、このZIPのinstall_history202.pyに渡すと自動で１行を追加します。）
3. Vercel更新後、既存の『戦国の反省会』の直下に新カードが現れます。
   直接のURLは /history202-chat.html です。

■ 公開設定
history202/config.json の mode は「reader」です。現在は31話全てを目次から読めます。
リアルタイムで順番に配信する場合は、開始日時を決めた段階で mode を「broadcast」、
startAtを「2026-11-10T10:00:00+09:00」のような形式に変更してください。
ただし「reader」のままでも公開の読み物として使えます。

■ 既存機能への影響
・sengoku-chat/ 以下、himiko API、共有グルチャ、ほかの学習機能には変更不要
・GitHubの現在のhimiko.htmlを「古いファイル」で丸ごと上書きしないでください
・自動追加用のinstall_history202.pyは元のhimiko.htmlをバックアップします
・これまでの「戦国の反省会」の配信はそのまま動きます

■ 制限
このZIPは追加するファイル一式です。アプリ本体の最新版himiko.htmlを同梱していないため、
一覧カードを表示するには上記のスクリプト1行を最新版himiko.htmlに追加する必要があります。
開発中のGitHub接続は読み込みに成功しましたが、書き込みは権限エラー（403）でした。
完成した配布ファイルをこちらで作成した状態で、本番GitHubへ直接は反映していません。
