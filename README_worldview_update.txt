【変更内容】
・人物は、それぞれの異次元から言葉だけでチャットにつながるという前提を、毎回の生成に追加。
・人生を振り返り、後世の出来事も知識として話せる。生前の体験と後世の知識は区別する。
・言語や時代の違いを越えて現代日本語で通じる。既存の口調・主従関係の敬意等は維持。
・天国や共通の架空都市・駅を設定しない。
・直接会う、待ち合わせ、同行、発送等の実行可能な約束を作らない。
・チャットで再び話す約束や「もし会えたら」という空想、別々の暮らしの話は楽しめる。
・実在の史跡の質問や、史実上の対面まで否定しない。
・以前の待ち合わせ発言を聞き返されたら、架空の道案内を追加せず、短く訂正して会話に戻る。
・正体を聞かれた場合はAIによる創作であることを率直に答える。
・昔の「現代でチャット民」の前提と、散歩へ誘う会話例を修正。

UI、DB、通知、ログイン、参加承認、人物データは変更していません。
すべての過去の履歴を読み込む機能や、記憶・地図は追加していません。

【反映の範囲】
新しく生成される会話に適用されます。
すでに保存・生成済みの会話や配信待ちの文章は書き換えません。
そのため、更新後もしばらく旧設定で生成済みの発言が届く可能性があります。
自動会話を確認するときは、生成済みの配信が終わり、新しく生成される場面で確認してください。
