変更点

- Supabaseデータ、APIや1人用グルチャの処理は変更していません。

重要な注意
?test=1 はログイン画面の表示切替であり、サーバー側の認証・アクセス制限ではありません。
一般のユーザーの利用を厳密に遮断する必要がある場合は、別途サーバー側のメール許可リストまたは認証制限が必要です。
既存の招待URLからは通常の「準備中」画面が表示されるため、招待テストをする場合は ?test=1 を付けた別途テストURLを使用してください。

既存4ファイルを同じパスで上書きしてください。追加のSupabase/Vercel設定は不要です。
