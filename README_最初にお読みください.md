## 結論

複数人で同じ異次元グルチャを共有することは実現できます。管理者も参加者も同じアプリを使い、管理者にだけ管理操作を表示する構成にできます。最初から別の管理サイトを契約する必要はありません。

ただし、リンクを共有するだけの変更ではありません。現在の「端末ごと」の管理に加え、「ログインした利用者」「グループ」「グループ共通の会話」を保存する仕組みが必要です。

このZIPは、**調査・設計と、人間同士で共有を検証する第1段階の実装**です。AI歴史人物を含む共有グルチャの完成版ではありません。Supabaseとメール配信の設定が必要です。設定前は準備中になり、既存のアプリの動作には入り込みません。本番への反映・外部サービスの契約は行っていません。

## 入れ方

ZIP内の `api/shared-chat.js`、`shared-chat.html`、`shared-chat/` を、既存リポジトリの同じ階層に追加します。既存ファイルの置き換えはありません。`tests/` とこの説明書は開発・確認用です。

設定の詳細は `shared-chat/SETUP.md`、調査と今後の構成は `shared-chat/調査と設計.md` を参照してください。

設定後の入口は `https://現在のアプリのドメイン/shared-chat.html` です。既存のNekopon画面には入口を追加していません。検証が終わった段階で追加する想定です。

## 最初の検証の範囲

管理者1人・家族または関係者2〜3人の部屋で、作成→招待→申請→承認→共有投稿→削除→退出の流れを確認します。承認するとその部屋の過去の会話も読めます。招待時に、その扱いを伝えてください。

メール認証はメールアドレスの利用権限を確かめるものです。保護者・生徒本人であることや保護者の同意は、管理者が普段の連絡手段で確認してから承認する運用です。
