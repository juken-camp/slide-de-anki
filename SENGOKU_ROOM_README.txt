# 戦国の反省会 — 今回の実装 (2026-11-07)

- `himiko.html`: 「異次元グルチャ」と「みんなで異次元グルチャ」の間に一覧カードを追加。新しい閲覧専用ルームをオーバーレイで開き、戻ると一覧のスクロール位置を復元します。
- `sengoku-chat.html`: 既存 `himiko.html` のグルチャ画面をもとにした閲覧専用画面。送信欄・送信ボタン・参加機能はありません。
- `sengoku-chat/original-chat.css`: 既存チャットのCSSを抽出したもの。元の見た目を再利用します。
- `sengoku-chat/room.css`, `sengoku-chat/room.js`: 部屋固有の最小限の表示・閲覧・検索・参加者一覧・テーマ連動処理。
- `sengoku-chat/schedule.json`: 後から会話・画像を登録するための空の配信ファイル。現在は `messages: []` で、予定された会話は存在しません。

## 後からの配信原稿
`messages` に `[{"at":"2026-11-10T10:00:00+09:00","senderId":"nobunaga","name":"織田信長","role":"historical","text":"...","avatar":"history-icons/001.webp"}]` の形式で追加すると、公開日時以降にすべてのユーザーへ同じ会話が表示されます。現代人役は `role: "modern"` で右側に表示されます。日時は日本時間のオフセット込みで設定してください。`participants` は `[{"id":"nobunaga","name":"織田信長","avatar":"history-icons/001.webp"}]` 形式です。`image` はグループ画像の相対パス、未設定なら空の画像枠を表示します。

## 制限と動作
- いまは会話原稿が未登録なので、ユーザーには「会話はこれから始まるぜ！」と表示されます。これは予約配信を行ったという意味ではありません。
- AIのAPIは呼びません。全員が同じJSONを取得するだけです。
- 時刻が来たかを約30秒間隔で確認します。配信ファイル自体の再取得は5分ごとです。通知は未実装です。
- 既存の個別チャット・異次元グルチャ・みんなで異次元グルチャのAPI処理やデータは変更していません。
