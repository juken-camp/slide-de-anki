組込とダウンロードの仕様:
- 「history202/local-images.json」に格納されたローカル画像が最優先（既存の仕組みを維持）
- GIF/PDF/リンクURLを画像として誤保存しない。読み込めた画像だけをWebPに変換し、最大1400pxに縮小
- 同一出典で複数項目に使うときは、同じ資料を一度取得して複製保存
- Wikimedia Commons は実際のAPIメタデータで PD / CC BY / CC BY-SA / CC0 だと確認できたファイルのみ取得
- 参照元ごとの史料・年代・作者の違いは公開前に人の目で再確認
- GitHub Actions の "Download History 202 authentic images" を実行すると、画像取得と監査を行い「history202-images-patch」というArtifact ZIPを生成する
- このチャットの環境では外部画像サイトを名前解決できず、ダウンロードを実行できていません。GitHubへの更新も行っていません
