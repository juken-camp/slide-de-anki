## 本文ページへの更新（GitHub Actions）

1. ZIPを展開し、フォルダー構成を保持したまま、**GitHub main の同じパス**へ追加・更新ファイルをアップロードします。
2. GitHub → **Actions** → **History 202 verified document pages** → **Run workflow**。
3. 実行結果に `Updated: 2/2` と出たことを確認。そこで初めて、次の2画像は実際の本文ページへ更新完了です。

- `law-17article`: 1939年刊『聖徳太子十七条憲法』**PDF第3ページ**。実際の第一条「以和為貴」を掲載。ただし604年の原本ではなく1939年の書写資料です。
- `period-1879-conscription-cartoon`: 1873年『徴兵令 官版』**PDF第2ページ**。徴兵についての告諭の本文です。

取得に失敗した画像は元ファイル・元説明のまま保持されます。**ZIPをアップロードするだけでは、PDF原本の新しい2画像はまだ取得されません。**
