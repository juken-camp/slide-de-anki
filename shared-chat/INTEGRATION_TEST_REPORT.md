## 実行方法

```bash
cd tests
npm ci
npm test
node --test himiko-modes.test.cjs integrated-reply.test.cjs integrated-live.test.cjs shared-ai.test.cjs worldview.test.cjs conversation-plan.test.cjs
```

既存の画面テストは、認証情報にrefresh tokenを含め、入力イベントを発火するようにテストデータを修正しました。既存の認証処理と、空入力時に送信ボタンを無効化する実装に合わせるためです。
